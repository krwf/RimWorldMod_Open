# Do work right now

림월드의 작업 탭에서 한 종류의 작업을 지정해, 그 작업에 할당된 정착민들이
다른 작업·욕구·시간표보다 해당 작업을 먼저 수행하게 만드는 모드입니다.

버전: **1.0.0** · 제작일: **2026-10-29**

## 설치

1. ZIP을 압축 해제합니다.
2. 안에 있는 **DoWorkRightNow** 폴더를 림월드 설치 폴더의 **Mods** 안에 넣습니다.
   최종 경로가 `RimWorld/Mods/DoWorkRightNow/About/About.xml`이면 맞습니다.
3. 모드 목록에서 **Harmony**와 **Do work right now**를 활성화합니다.
4. 로드 순서는 `Harmony → Core 및 사용하는 DLC → Do work right now`로 둡니다.
5. 게임을 재시작합니다.

필수 선행 모드는 **Harmony 하나**입니다. 게임 버전에 맞는 최신 Harmony를 사용하세요.
HugsLib, HAR, 다른 작업 관리 모드는 필수가 아닙니다.

1.6과 1.7의 DLL이 함께 들어 있습니다. 게임 버전에 맞는 파일이 자동으로 선택되므로
사용자가 DLL을 이동하거나 별도로 빌드할 필요가 없습니다.

## 사용법

1. 하단의 **작업** 탭을 엽니다.
2. **높은 중요도**와 **낮은 중요도** 사이에 있는 **⚠** 버튼을 클릭합니다.
3. 같은 경고 아이콘이 마우스 커서 옆에 붙습니다.
4. 강제할 **작업 열의 이름**을 클릭합니다. 정착민 행의 체크 칸을 클릭하는 것이 아닙니다.
5. 해당 작업이 체크돼 있거나 수동 우선순위가 1 이상인 정착민에게 명령이 적용됩니다.

| 조작 | 결과 |
|---|---|
| ⚠ 버튼 클릭 | 작업 선택 도구 켜기/끄기 |
| 도구를 켠 상태에서 작업 이름 클릭 | 그 작업을 강제 |
| 이미 강제 중인 같은 이름 다시 클릭 | 강제 해제 |
| 다른 작업 이름 클릭 | 강제 작업을 그 작업으로 변경 |
| Esc 또는 우클릭 | 선택 도구만 종료 |
| 작업창 닫기, 다른 맵으로 전환 | 선택 도구만 종료 |

**선택 도구를 닫아도 강제 명령은 유지됩니다.** 해제하려면 작업 탭에서 ⚠를 켜고,
붉게 표시된 작업 이름을 다시 클릭하세요.

일시정지 중에도 명령을 설정할 수 있습니다. 실제 이동과 작업 진행은 게임을 재개한 뒤
이루어집니다. 맵마다 한 종류의 작업을 강제할 수 있으며, 다른 맵의 선택은 별개입니다.

## 정착민이 행동하는 방식

- 선택한 작업을 실제로 수행할 수 있으면 식사, 수면, 오락, 시간표보다 먼저 수행합니다.
- 그 정착민이 수행할 수 있는 해당 작업이 없을 때는 욕구 행동이나 대기가 허용됩니다.
  이때 다른 종류의 일반 작업으로 넘어가지는 않습니다.
- 작업 가능 여부는 게임의 작업 탐색으로 판단합니다. 대상 지정, 재료, 접근 가능 여부,
  다른 정착민의 예약, 금지 설정 등 기본 조건을 그대로 따릅니다.
- 작업이 다시 생겼는지 정착민별로 60게임 틱마다 분산 확인하고, 가능한 작업을 찾으면
  욕구 행동을 중단하고 복귀합니다. 일시정지 중에는 이 확인 시간이 진행되지 않습니다.
- 이미 같은 작업을 수행 중인 정착민은 불필요하게 같은 일을 중단·재시작하지 않습니다.
- 강제 명령을 적용하면 해당 정착민의 기존 대기 명령을 취소합니다. 활성 상태에서
  강제 작업을 시작할 때도 경쟁하는 대기 명령을 정리합니다.
- 기존 작업의 필수 마무리 동작은 게임의 정리 절차를 따릅니다.
- 해당 작업의 체크를 끄거나 우선순위를 0으로 내리면 그 정착민은 강제 대상에서 빠집니다.
  나중에 체크하면 다시 포함됩니다. 기존 우선순위 값 자체를 모드가 바꾸지는 않습니다.
- 강제 대상에는 작업 가능한 플레이어 정착민과 식민지 노예가 포함됩니다.
  동물·메카노이드·죄수의 행동 제어를 추가하지는 않습니다.
- 소집, 다운, 정신이상, 몸에 붙은 불 등 게임의 상태·긴급 반응은 기존 제어를 따릅니다.
  일반 소방·치료 같은 다른 작업은 선택한 작업을 대신하지 않습니다.

배고픔·피로·오락 수치를 동결하거나 회복시키는 모드는 아닙니다. **욕구 행동을 뒤로 미루는
기능**이므로, 작업이 계속 있으면 욕구 수치는 계속 낮아집니다.

모드가 추가한 작업도 표준 작업 열과 작업 탐색기를 사용하면 같은 방식으로 처리합니다.
실행할 자동 작업이 전혀 정의되지 않은 열은 안내 메시지를 띄웁니다.

## 화면 표시와 저장

- 선택 도구가 켜져 있거나 강제 명령이 유지되는 동안, 작업창 외곽과 하단 작업 탭 버튼에
  빨간 그라데이션 테두리를 표시합니다.
- 선택한 작업 이름에도 붉은 배경과 테두리를 표시합니다.
- 버튼·작업 제목에 마우스를 올리면 상태와 조작 방법을 볼 수 있습니다.
- 강제 작업은 세이브에 맵별로 저장됩니다.
- 커서의 도구 선택 상태는 저장하지 않습니다. 불러온 뒤에는 필요한 경우 ⚠를 다시 켜세요.
- 한국어와 영어 UI 문구를 포함합니다.

## 호환성과 검증 범위

| 대상 | 빌드에 사용한 게임 참조 | 대상 런타임 |
|---|---|---|
| RimWorld 1.6 | 1.6.4871 | .NET Framework 4.7.2 |
| RimWorld 1.7 | 1.7.4990-unstable | .NET 10 |

두 버전의 실제 참조 어셈블리에 맞춰 각각 컴파일하고, 패치할 메서드와 주입할 인수·필드의
형식을 별도로 검사했습니다. 게임 어셈블리와 Harmony DLL은 배포 파일에 포함하지 않습니다.

**이 제작 환경에는 실행 가능한 림월드가 없어 실게임 실행 검증은 하지 못했습니다.**
컴파일/API 검사 결과와 실제 게임에서의 동작 확인은 구분해야 합니다.
1.7은 제작 시점에 불안정 테스트 브랜치이므로 후속 업데이트에 따라 재빌드가 필요할 수 있습니다.
작업창이나 AI를 크게 교체하는 다른 모드와의 조합은 개별적으로 확인해야 합니다.

상세 빌드 결과는 `VALIDATION.md`, 재빌드 방법은 `BUILDING.md`, 게임에서 확인할 항목은
`TESTING.md`에 있습니다. 오류 확인 시 로그의 `[Do work right now]` 문구와 게임 버전을
함께 확인하면 원인을 좁히는 데 도움이 됩니다.
